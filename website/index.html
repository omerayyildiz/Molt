Questions

Is it safe to delete node_modules?

Yes. It's rebuilt from package.json the next time you run npm install, pnpm install, yarn or bun install. Molt marks it Caution because reinstalling takes a moment and needs a connection.

Why doesn't Molt search my Documents folder?

macOS asks for permission before an app reads Desktop, Documents or Downloads. Molt skips them unless you add a project folder there in Settings, so you never see a surprise prompt.

How is the App Store version different?

It runs in Apple's sandbox, which hides most other apps' caches and doesn't allow developer tools to run. The direct download has every rule.

Does Molt send any data?

No. Molt has no analytics and makes no network requests. Your cleanup history stays on your Mac.
